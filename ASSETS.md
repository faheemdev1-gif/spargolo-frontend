# Asset provenance

The venue, family, food imagery, food clips, and bundled fonts were retrieved for the existing private design concept from the competitor reference supplied by the user: `https://demo.hermesagency.it/spargolo/`. Food poster frames were extracted from those clips. The custom SVG favicon was created for this project.

The files are included so the React export reproduces the design without depending on that reference site's availability. This project does not grant ownership or new redistribution rights to third-party photographs, video, or fonts. Obtain the venue's original assets and confirm permission for public reuse, including font licensing, before publishing the public client site. Replace files in `public/assets/` and update paths in `src/data/site.js` when originals are supplied.

Menu names, descriptions, compositions, and prices are illustrative. They are not a verified menu or allergen declaration.

The reviews section reproduces short, attributed excerpts from the Google reviews shown in the user-provided reference. These are not a live Google feed; no aggregate rating or review count is claimed. The source note is displayed with the section. Review text and source links should be confirmed with the owner for the final content.
